Vanillalua language reference

Vanillalua language

This reference covers the current Vanillalua syntax and the engine APIs exposed by Vanilla3D. The standalone playground emulates core language behavior and a small in-memory scene; it does not connect to the editor or render objects.

1. A first script

Every Vanillalua script should begin by loading the Scripts space and the Instance module. Add other spaces with call when you need to access them.

call Scripts
call World
get Instance

local block = Instance.create("prism6", World)
block.Position = vanilla3D.Position(0, 10, 0)
print("Created:", block)

call World loads the World space. get Instance loads the instance API, and get Scripting loads scripting utilities for UID lookup and reassignment. Setup lines belong at the top of the script.

2. Variables: local and global

local name = value creates a variable scoped to the current script block. A variable assigned without local is a global variable: all scripts can read it while the simulation is running.

call Scripts
get Instance

local privateCount = 1
sharedCount = 10
print(privateCount)
print(sharedCount)

Global write permissions: the script that first creates a global may update it, and any Server script may update any global. Other Local scripts can read globals but cannot change them. Use a Server script for values that need to be centrally controlled. Global variables are runtime state and are cleared when a new simulation starts or the simulation stops.

Use clear, descriptive names for globals to avoid accidentally sharing the same name between scripts. Local variables are best for temporary values and implementation details.

# Server script
sharedScore = 0

# Any script can read this:
print(sharedScore)

# The script that created sharedScore can update it,
# and Server scripts can update it too.
sharedScore = sharedScore + 1

3. Values and types

  • Numbers: 12, 3.5, 0.25. Decimal literals support up to two digits after the decimal point.
  • Strings: "hello" or 'hello'. Use \n for a newline and \t for a tab inside a string.
  • Booleans: True and False.
  • Nil: nil represents no value.
  • Instances: references to objects in the scene, such as the result of Instance.create().
  • Vectors: three-number values used for positions and sizes.

Comments start with # and continue to the end of the line.

4. Printing output

Use print(...) to send values to the Output panel. You can print strings, numbers, variables, instances, vectors, and multiple values.

call World
get Instance
local score = 125
local block = Instance.create("prism6", World)
print("Score:", score)
print("Block ID:", block)
print("Position:", block.Position)

Instances print their unique ID, such as Cobalt092. Multiple arguments are separated in the output. If an instance has been deleted, its printed value is deleted instance.

5. Waiting and timed scripts

wait(seconds) pauses the current script for the specified number of seconds. The argument must be a non-negative number with up to two decimal places. Waiting yields to other scripts and the simulation; it does not freeze the whole editor.

call Scripts
call World
get Instance

local block = Instance.create("prism6", World)
block.Position = vanilla3D.Position(0, 0, 0)
for i in 1, 5 do
    block.Position.Y = block.Position.Y + 1
    print("Step", i, "Y =", block.Position.Y)
    wait(0.5)
end

Use wait(0) to yield without an intentional delay. A long-running while loop yields between iterations, so other scripts can continue running.

6. Operators

  • Math: +, -, *, /, %
  • Comparisons: ==, ~= or != (not equal), <, >, <=, >=
  • Logic: and, or, not
  • Grouping: parentheses such as (a + b) * 2
  • String joining: use + when at least one operand is a string, e.g. "Score: " + score.

Math operators require numbers, except vector addition/subtraction and vector multiplication by a number. In conditions, nil and False are false-like; other values are true-like.

7. Conditions

local temperature = 18
if temperature >= 25 then
    print("Warm")
else
    print("Cool")
end

Conditions use if, optional else, and end. Comparisons can be combined with and, or, and not. There is no elseif; nest another if inside else instead.

8. Loops

A numeric for loop includes both its start and end values:

for i in 1, 4 do
    print("Iteration", i)
end

A while loop repeats while its condition remains true. Make sure something changes the condition so the loop can finish.

local count = 0
while count < 3 do
    count = count + 1
    print(count)
    wait(0.25)
end

9. Spaces and instance lookup

Available spaces are World, Storage, and Scripts. Load each with call before using it. Existing instances must be accessed by their unique ID (UID), not by their display name. Use Instance.GetUID(name) to find an ID by object name.

call World
get Scripting
get Instance

local blockUID = Instance.GetUID("Block")
local block = World.blockUID
print(block.Name)

When a dot member on a Space matches a local variable, its string value is treated as the UID. Bracket lookup also works: World[blockUID]. You can pass the Space to GetUID when names are duplicated, for example Instance.GetUID("Block", World).

10. The Instance module

  • Instance.create(type, space) — creates and returns an instance. Supported types: "prism6", "script", and "worldsettings".
  • Instance.duplicate(instance) — duplicates an instance in its current space.
  • Instance.duplicate(instance, space) — duplicates it into a chosen loaded space.
  • Instance.delete(instance) — deletes the instance. References to it become deleted references.
  • Instance.GetUID(name) — returns the unique ID of an existing instance with that display name. Optionally pass a Space as the second argument to disambiguate duplicates.
  • Instance.SetUID(oldUID, newUID) — changes an instance's unique ID. The new UID must be unique and contain only letters and numbers, starting with a letter.
call World
get Instance

local original = Instance.create("prism6", World)
original.Position = vanilla3D.Position(0, 3, 0)
local copy = Instance.duplicate(original, World)
copy.Position = vanilla3D.Position(2, 3, 0)
print("Original:", original)
print("Copy:", copy)
Instance.delete(copy)

Find and change a unique ID

call World
get Scripting
get Instance

local blockUID = Instance.GetUID("Block")
local block = World.blockUID

Instance.SetUID(blockUID, "Ashburn534")
blockUID = Instance.GetUID("Block")
block = World.blockUID
print(blockUID)
print(block)

SetUID rekeys the existing instance; it does not rename the visible Name property. Refresh the UID variable after changing it, then retrieve the instance again. If more than one object has the same name, provide its Space to GetUID.

11. Properties and vectors

Read or set properties using instance.Property. Properties are validated by the engine, so a property expects the correct kind of value.

Applies toProperties
Every instanceName (string), Type (read-only), Parent (a Space or an instance)
Prism blocksPosition, Size (vectors, each axis at least 0.05 for Size), Locked, Anchored, ReactsToPhysics, Collidable, Wireframe, FaceColoring, ShowLabels (True or False)
World SettingsTimeOfDay (0 to 24), Gravity (0 to 1000), KillLayer (number)
ScriptsRun, a function: myScript.Run() starts that script

vanilla3D.Position(x, y, z) and vanilla3D.Size(x, y, z) create three-component vectors. Vector axes are uppercase X, Y, and Z. For a prism, Position maps to its world coordinates; Size maps to width, height, and length respectively.

call World
get Instance
local block = Instance.create("prism6", World)
block.Position = vanilla3D.Position(2, 5, 0)
block.Size = vanilla3D.Size(2, 1, 3)
block.Anchored = True
print(block.Position.X, block.Position.Y, block.Position.Z)

11b. Parents and the script variable

Inside every running script, script is a built-in variable that always refers to the script itself. Its Parent is the object the script sits under, or a Space if it is not inside an object.

call Scripts
get Instance

local part = script.Parent
part.Anchored = True
print("Controlling", part.Name)

# Reparent: put a new script inside the block
local child = Instance.create("script", World)
child.Parent = part

Read Parent from any instance. Assign it an instance or a Space to move it. An instance cannot become its own parent or a child of its own descendant. If a script is not inside an object, script.Parent is its Space, such as Scripts.

12. Script types and running

  • Server: trusted script type for shared/global updates. Server scripts can modify any global variable.
  • Local: can read global variables and modify only globals it originally created.
  • Run When: Simulation: runs when Run starts the simulation.
  • Run When: Join: reserved for join-trigger behavior if supported by the current project workflow.
  • Run When: Manual: starts only when manually invoked, for example through the script's Run property.

When the simulation starts, Server scripts begin before Local scripts. A JSON script cannot be run. Stopping the simulation stops active script tasks and restores the scene snapshot from before Run. Runtime globals are cleared as part of ending the simulation.

13. Full example: shared status and moving block

# Server script
call Scripts
call World
get Instance

moveStatus = "Starting"
local block = Instance.create("prism6", World)
block.Position = vanilla3D.Position(0, 1, 0)
moveStatus = "Moving"
for step in 1, 6 do
    block.Position.Y = block.Position.Y + 1
    print(moveStatus, "step", step, "position", block.Position)
    wait(0.25)
end
moveStatus = "Finished"
print(moveStatus)

14. Current syntax and standalone API support

The playground accepts the current engine parser's statement and expression forms: call and get setup lines, property access, bracket indexing, chained calls, assignments to properties, vector arithmetic, and calls with multiple arguments. It emulates the current instance types: prism6, ball, model, script, and worldsettings.

call Scripts
call World
get Instance
get Scripting

local ball = Instance.create("ball", World)
ball.Position = vanilla3D.Position(0, 4, 0)
ball.Rotation = vanilla3D.Position(0, 45, 0)
ball.Velocity = vanilla3D.Position(1, 0, 0)
local uid = Instance.GetUID(ball.Name, World)
print(World[uid].Position + vanilla3D.Position(0, 1, 0))
Instance.SetUID(uid, "MyBall01")

Standalone limitations: this playground emulates instances and spaces for learning and syntax testing; it does not change the live Vanilla3D project, run separate scripts, or simulate physics. wait(seconds) is accepted as a no-op in this synchronous playground. Engine-only behavior may differ from the full editor.

Standalone simulator: World, Storage, Scripts, Instance, vectors, properties and wait() are emulated in memory. No editor scene is changed; execution is step-limited.
