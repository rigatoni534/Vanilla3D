Extra info / EDITOR

Editor

The Vanilla3D editor is powerful game engine that runs in your browser, and requires minimal system resources. It has an interface and building system similar to that of another engine, Roblox Studio, while keeping it simple and useful.

Extra info / LANGUAGE

Language

Vanilla3D uses a custom scripting language that is simple and powerful, called Vanillalua, based off of Lua or Luau by Roblox. It focuses on simplicity but power, and efficiency.
