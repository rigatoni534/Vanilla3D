Vanilla3D

The Web Based 3D Game Engine.

A lightweight, open-source 3D game engine that runs right in your browser.

About Vanilla3D

Vanilla3D, is a light, HTML based 3D game engine made for creating and SOON playing 3D games. Vanilla has a capable editor that will allow you to make good games for anyone to play in the browser using the eventual player site.

Editor

The Vanilla3D editor is a powerful game-building tool that runs in your browser and requires minimal system resources. Its interface and building system are similar to Roblox Studio, while keeping things simple and useful.

Try it ↗

Language

Vanilla3D uses Vanillalua, a custom scripting language based on Lua and Roblox Luau. It aims to balance simplicity, capability, and efficiency.

Try it ↗

Player

A standalone way to play Vanilla3D games in the browser is planned for the future, once the engine can support playable games.
