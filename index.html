01 — Editor

A world builder that feels like a tool, not a demo.

Place prisms, balls, wedges, cylinders and real boolean unions. Scrub the sun, hang lights, paint 15 procedural materials, and test physics without leaving the viewport. Runs on WebGL2 and falls back to a 2D renderer.

  • Explorer, properties, tabs and a 100-step undo
  • Materials, lights, effects, textures and UI instances
  • Autosave to three browser slots or a portable .vnw file

02 — Language

Vanillalua, a scripting language you can read.

Familiar syntax, a real interpreter, and live output in the editor. Spawn parts, read touches, drive UI, play sounds, and split work across server and local scripts — then try the same code in the standalone playground.

  • Spaces, instances, events and threads
  • Server, local and manual execution
  • A full language reference with search

04 — Player

Open a world and press play.

The Player loads a .vnw from your computer, a URL or the last world you played. Play solo, host a lobby, or join with a five-character code. Guests receive the host's world and play together.

  • File picker, drag-and-drop and https URLs
  • Trust prompt before any script runs
  • Host and join lobbies over WebRTC

Under the hood

Small engine. Real pieces.

Fast by default

Six graphics presets, pooled particle sims and a renderer that stays usable on low-end machines.

Yours to keep

Worlds are plain JSON. Save to the browser, export a .vnw, or take the whole editor offline as a ZIP.

Peer to peer

Five-character rooms, validated edit batches and a host-authoritative play mode. No backend to run.

Built on the web

No plugins and no native dependencies. A modern browser, a canvas and a few hundred kilobytes of JavaScript.
