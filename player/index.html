Ask the host for their 5-character room code. The host sends the world to you; this browser does not need a copy.

The Player uses the same engine as the editor. Worlds with scripts run those scripts locally when you play solo. A guest joins the host's session, receives the host world and controls a guest avatar while the host runs the simulation. Everyone in a room needs the same 4.0 network version.
