Daylight Cycle

Script

Moves the time of day smoothly, so a whole day passes in a few minutes: sunrise, sunset, a short night, and back to morning. Nothing in the world has to be touched.

  • Adds one Server script that runs with the simulation
  • Needs a World Settings named Settings in World
  • A full day takes 8 minutes; change dayMinutes to taste
Download .vanilla
View the script 
call Scripts
call World
get Instance
get Scripting

local dayMinutes = 8
local tick = 0.1
local step = 24 * tick / (dayMinutes * 60)

local uid = Instance.GetUID("Settings", World)
local settings = World[uid]
settings.TimeOfDay = 6

while True do
    local hour = settings.TimeOfDay + step
    if hour >= 24 then
        hour = hour - 24
    end
    settings.TimeOfDay = hour
    wait(tick)
end

Player Stats HUD

UI

A compact player panel with a name and live bars for health and stamina. Its Local script waits for player.ModelAdded, so it works even when the model is not ready as the simulation starts.

  • Adds a Frame, two ProgressBars, three labels and one Local script
  • Needs a player model with a Human inside, like the default setup
  • Bars scale to MaxHealth and MaxStamina
Download .vanilla
View the script 
call Scripts
call Players
get Instance

player = Players.LocalPlayer
hp = script.Parent.Health
stamina = script.Parent.Stamina
playerName = script.Parent.PlayerName

function refresh()
    local character = player.Character
    if character ~= nil then
        local human = character.Human
        if human ~= nil then
            hp.Length = human.Health / human.MaxHealth * 100
            stamina.Length = human.Stamina / human.MaxStamina * 100
        end
    end
end

function setup(character)
    local human = character.Human
    if human ~= nil then
        refresh()
        human.HealthChanged:Connect(refresh)
        human.StaminaChanged:Connect(refresh)
    end
end

player.ModelAdded:Connect(setup)
if player.Character then setup(player.Character) end

Spinning Platform

Script

Creates an anchored metal platform and turns it forever. Drop it into an obstacle course, a lobby centrepiece, or anywhere that needs a little motion.

  • Creates its own 6 × 0.8 × 6 Vm platform
  • Set speed at the top: 1.2 is a lazy turn, 8 is fast
  • Runs on the server, so every player sees the same angle
Download .vanilla
View the script 
call Scripts
call World
get Instance

local speed = 1.2
local platform = Instance.create("prism6", World)
platform.Name = "SpinningPlatform"
platform.Position = vanilla3D.Position(0, 1, 0)
platform.Size = vanilla3D.Size(3, 0.4, 3)
platform.Anchored = True
platform.Material = "metal"

local angle = 0
while True do
    angle = angle + speed
    if angle >= 360 then
        angle = angle - 360
    end
    platform.Rotation = vanilla3D.Position(0, angle, 0)
    wait(0.05)
end

Orbit Light

Script

A warm point light circles the origin and lights the scene as it moves. A quick way to add moving shadows and a bit of life to a night build.

  • Creates one point light with shadows and a 16 Vm range
  • Follows a 16-step path, so no maths libraries are needed
  • Change the y value in the path to lift the orbit
Download .vanilla
View the script 
call Scripts
call World
get Instance

local light = Instance.create("light", World)
light.Name = "OrbitLight"
light.Brightness = 2
light.Range = 16

local path = {
    {4, 0}, {3.7, 1.5}, {2.8, 2.8}, {1.5, 3.7},
    {0, 4}, {-1.5, 3.7}, {-2.8, 2.8}, {-3.7, 1.5}
}
local index = 1
while True do
    local point = path[index]
    light.Position = vanilla3D.Position(point[1], 3, point[2])
    index = index + 1
    if index > 8 then index = 1 end
    wait(0.18)
end
