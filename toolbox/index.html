Daylight Cycle

Script

Moves the time of day smoothly, so a whole day passes in a few minutes: sunrise, sunset, a short night and back to morning. Nothing in the world has to be touched, so it works in any scene with a World Settings in it.

  • Adds one Server script that runs when the simulation starts
  • Needs a World Settings named Settings in World
  • A full day takes 8 minutes: change dayMinutes to taste

# Daylight Cycle: shifts the time of day smoothly, so a whole day passes in a few minutes.
# Needs a World Settings named "Settings" in World, which every new world starts with.
call Scripts
call World
get Instance
get Scripting

local dayMinutes = 8        # how long one whole day takes
local tick = 0.1            # seconds between updates
local step = 24 * tick / (dayMinutes * 60)

local uid = Instance.GetUID("Settings", World)
local settings = World[uid]
settings.TimeOfDay = 6

print("Daylight Cycle running. One day takes", dayMinutes, "minutes.")

while True do
    local hour = settings.TimeOfDay + step
    if hour >= 24 then
        hour = hour - 24
    end
    settings.TimeOfDay = hour
    wait(tick)
end
